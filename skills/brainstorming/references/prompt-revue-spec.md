# Grille de Revue de Document de Spécification

Utiliser cette grille lors de l'auto-revue du document de spécification de design.

**Objectif :** Vérifier que la spécification est complète, cohérente et prête pour la phase de planification.

## Éléments à Vérifier

| Catégorie | Élément à contrôler |
|---|---|
| **Complétude** | Aucun TODO, placeholder, "TBA" ou section incomplète. |
| **Cohérence** | Aucune contradiction interne entre les modules ou les exigences. |
| **Clarté** | Exigences suffisamment explicites pour éviter tout doute d'implémentation. |
| **Périmètre (Scope)** | Suffisamment concentré pour un plan d'implémentation unique. |
| **Principe YAGNI** | Aucune fonctionnalité superflue ou sur-ingénierie non demandée. |

## Règle de Tolérance

N'interrompre le processus que pour les problèmes réels pouvant impacter la planification. Les ajustements cosmétiques ou de style ne doivent pas bloquer le passage à la planification.
